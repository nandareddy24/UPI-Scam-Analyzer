# Scam Shield AI - Chrome Extension & Android Companion Package

## Chrome Extension Installation Guide
1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** using the toggle switch in the top right corner.
3. Click **Load unpacked**.
4. Select the directory: `c:\Users\DELL\Documents\UPI-Scam-Analyzer\extension`.
5. Click the Scam Shield icon in your Chrome toolbar to run instant UPI, URL, or SMS scans!

## Android Companion WebApp Package
1. Ensure your local Flask app or production URL is running at `http://<your-ip>:5000`.
2. Open Android Chrome browser on your mobile device.
3. Navigate to `http://<your-ip>:5000/dashboard`.
4. Tap Chrome menu (`⋮`) -> **Add to Home screen** / **Install App**.
5. Scam Shield AI installs as a standalone Progressive Web App (PWA) on your Android device!
